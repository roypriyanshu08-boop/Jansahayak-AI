# JanSahayak AI - React Frontend

Glassmorphic React Vite Web Portal for JanSahayak AI.

## Features
- **Citizen Portal**: Complaint filing form, dashboard, tracking view, AI details display
- **Admin Portal**: Grievance management table, officer roster & assignment, analytics metrics
- **Auth**: JWT session preservation & role-based route protection
- **Services**: Modular Axios client layer interfacing with FastAPI endpoints

## Setup & Development

```bash
cd frontend
npm install
npm run dev
```
Default URL: `http://localhost:5173`
